## Proposal

### Abstract

#### Project Purpose

This application helps people to look up for companies and track their job applications.

#### Background/Motivation

When people are actively seeking job opportunities, it is easy for them to lose track of applications they have made. "My BFF just got an online assessment for Company X. Did I apply for that company?" "A recruiter reached out to me for a phone interview. Wait, what position did I apply for?" "The recruiter has not provided an update. When did we talk last time?" People keep asking themselves these questions and looking up archived emails in their mailboxes. This application will answer all these questions by outlining a clearer picture of the job-seeking process.

### Functional Specifications

#### Features

-   Users can create a session and add a list of active applications.
-   Users can update the status, track and see the whole flow of each job application.
-   Users can add notes for each job application.

### Future Enhancements

-   Pick a fancier name for the application
-   Create a login page and add a landing page with dashboards after login

## Implementation

### Data

#### Session Data

-   key: String
    -   YYYYM, where M = 0, 1, 2, 3, sorting purpose
-   name: String
    -   Spring / Summer / Autumn / Winter + year

#### Application Data

-   companyName: String
-   jobTitle: String
-   isActive: Bool
    -   User can turn it on or off. It is irrelevant to status.
-   tags: [String: Bool]
    -   Options: Is Referred, Has Worked
-   status: [String: String]
    -   Options: Planning, Applied, OA, On Campus, Phone, Onsite, Team Match, Offer, Accepted

#### Database Structures

High level:

-   username
    -   applications
        -   session
            -   companyName
            -   jobTitle
            -   isActive
            -   tags
                -   tag: bool
            -   status
                -   status: time
