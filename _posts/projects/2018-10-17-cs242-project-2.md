### The "Hub" Actors

The hub actor is Bruce Willis.

Source code:

```python
counts = [0] * len(actors)
for i in range(len(actors)):
    for j in range(i + 1, len(actors)):
        if m.is_costar(actors[i], actors[j]):
            counts[i] += 1
            counts[j] += 1
```

```shell

```

### Correlation between Age Group and Total Grossing

Actors with the age of 61 generate the highest total grossing. Actors with the age of 83 generate the highest average total grossing.

Source code:

```python
for name in m.actors:
    age = m.get_actor_by_key(name).age
    grossing = m.get_actor_grossing(name)
    if age > 0 and grossing > 0:
        counts[age] += 1
        sums[age] += grossing
avgs = [(0 if counts[i] == 0 else sums[i] * 1.0 / counts[i]) for i in range(150)]
```

### Correlation between Release and Grossing

Movies with the release date 1999 generate the most total and average grossing.

Source code:

```python
sums = [0] * 600
counts = [0] * 600
for name in m.movies:
    release = m.get_movie_by_key(name).release
    grossing = m.get_movie_grossing(name)
    if release > 0 and grossing > 0:
        try:
            counts[release - 1500] += 1
            sums[release - 1500] += grossing
            except Exception:
                pass
avgs = [(0 if counts[i] == 0 else sums[i] * 1.0 / counts[i]) for i in range(600)]
```

## Web API

Unittests are in `MovieMap/test/app/test_movie_map.py`.

For the manual test, the tester should test all `GET`, `PUT`, `POST` and `DELETE` endpoints including:

-   `GET`: Filters out all actors/movies not satisfying the requirements
-   `GET`: Returns the first actor/movie object that has the name and displays actor attributes
-   `PUT`: Update actors/movies information
-   `POST`: Add actors/movies
-   `DELETE`: Remove actors/movies

In each request, the tester can try different options.

All queries are case-insensitive, and the first letters of all inputs will be uppercase. The tester should test actors and movies separately. Here is an example of the test for actors, and the test for movie is the same.

### `GET` Requests

#### Filter by attributes

    /actors?attr={attr_value}

Single attributes

-   After making the request `http://127.0.0.1:5000/actors?name=bruce`, the tester should see a list of names containing _Bruce_.

    ["Bruce Dern", "Bruce Willis"]

Numeric attributes support a single value or range search. The tester should also check if the result value matches what the tester can get via a `GET` request as described later.

-   After making the request: `http://127.0.0.1:5000/actors?age=60`, the tester should see a list of names with age `60`.

    ["Eric Roberts", "Keith David", "Michael Biehn", "Tom Hanks"]

-   After making the request: `http://127.0.0.1:5000/actors?age=60-61`, the tester should see a list of names with age between `60` and `61`.

    ["Billy Bob Thornton", "Bruce Willis", "Eric Roberts", "Glenne Headly", "Jeff Daniels", "Keith David", "Michael Biehn", "Peter Gallagher", "Reba Mcentire", "Sandra Bernhard", "Tom Hanks", "Whoopi Goldberg"]

-   After making the request: `http://127.0.0.1:5000/actors?grossing=562709189`, the tester should see a list of names with grossing `562709189`.

    ["Bruce Willis"]

-   After making the request: `http://127.0.0.1:5000/actors?grossing=510000000-562710000`, the tester should see a list of names with grossing from `510000000` to `562710000`.

    ["Bruce Willis", "Faye Dunaway"]

Multiple attributes

-   After making the request `http://127.0.0.1:5000/actors?name=bruce&age=61`, the tester can test the `AND` logic.

    ["Bruce Willis"]

-   After making the request `http://127.0.0.1:5000/actors?name=bruce&age=62`, the tester should see an empty list since there is no data.

    \[]

-   After making the request `http://127.0.0.1:5000/actors?name=bruce|age=62`, the tester can test the `OR` logic.

    ["Bruce Dern", "Bruce Willis", "Dennis Haysbert", "Denzel Washington", "Kathleen Quinlan", "Ray Liotta", "Will Patton"]

-   **400 Bad Request**: After making the request `http://127.0.0.1:5000/actors?name=bruce|year=62`, the tester should see the _Bad Request_ page.

### `PUT` Requests

    curl -i -X PUT -H "Content-Type: application/json" -d '{attr={attr_value}}' http://127.0.0.1:5000/actors/{actor_name}

-   After entering the command `curl -i -X PUT -H "Content-Type: application/json" -d '{"grossing":500, "movies":["only one movie"]}' http://127.0.0.1:5000/actors/bruce_willis`, the tester should make the `GET` request `http://127.0.0.1:5000/actors/bruce_willis` again and test the change.

    {"name": "Bruce Willis", "url": "", "age": 61, "grossing": 500, "movies": ["Only One Movie"]}

-   If the tester includes unrecognized attributes, the changes of those unrecognized attributes will be discarded.

-   **400 Bad Request**: If the tester enters a non-existent name, he or she will get the message `The entry does not exist.`

### `POST` Requests

    curl -i -X POST -H "Content-Type: application/json" -d '{attr={attr_value}}' http://127.0.0.1:5000/actors

-   After entering the command `curl -i -X POST -H "Content-Type: application/json" -d '{"name":"billy joe", "movies": ["good movie"]}' http://127.0.0.1:5000/actors`, the tester should make the `GET` request `http://127.0.0.1:5000/actors/billy_joe`.

    {"name": "Billy Joe", "url": "", "age": 0, "grossing": 0, "movies": ["Good Movie"]}

-   **400 Bad Request**: After entering a command for _Billy Joe_ again, the tester should get the message `The content already exists.` and see the content unchanged since the page for Billy Joe already exists.

-   **400 Bad Request**: If the tester leaves out the `name`, he or she will get the message `Please specify the name.`

### `DELETE` Requests

    curl -i -X DELETE -H "Content-Type: application/json" http://127.0.0.1:5000/actors/{actor_name}

-   After entering the command `curl -i -X DELETE -H "Content-Type: application/json" http://127.0.0.1:5000/actors/bruce_willis`, the tester should make the `GET` request `http://127.0.0.1:5000/actors/bruce_willis` and see the page.

-   **400 Bad Request**: If the tester enters a non-existent name, he or she will get the message `The entry does not exist.`
