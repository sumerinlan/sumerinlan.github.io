## General UI

When launching the application, the tester should first see a page with a tab bar at the bottom. There are four sections: "Repositories", "Following", "Followers", "Profile".

### Repositories Page

The "Repositories" page contains information of a user's repositories, including the ones he or she owns or has contributed to. For each entry, the owner's username, the repository's name and the description are included.

#### Star/Unstar

The user can see whether he or she has starred the repository based on the color of the star. The user can star/unstar a repository via this app, and the change is reflected in the UI via the star icon and the count immediately.

#### External Link

Entries have a clickable external link. The test can enter webpage within the app. The tester can choose to open the webpage in Safari as well.

### Following Page

The "Following" page contains information of the users that user follows. For each entry, the user's username and the avatar are included.

| Following 1                                                              | Following 2                                                              |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| ![Following](/assets/posts/2018-11-08-cs242-project-3/2_following_1.png) | ![Following](/assets/posts/2018-11-08-cs242-project-3/2_following_2.png) |

Entries are clickable. The test can enter the "Profile" page for a particular user. The tester should notice that the current location is still in "Following" tab. The tester can tab the back button on the top and go back to the "Following" page.

### Followers Page

The "Followers" page contains information of the users's followers. Similarly, for each entry, the user's username and the avatar are included.

Entries are clickable. The test can enter the "Profile" page for a particular user. The tester should notice that the current location is still in "Followers" tab. The tester can tab the back button on the top and go back to the "Followers" page.

### Profile Page

The "Profile" page contains information of the users's information, including the avatar, name, username, created date, number of repositories, number of following, number of followers, and the bio.

Three counts are clickable. The test can enter the "Repositories"/"Following"/"Followers" pages by tabbing the buttons accordingly. The tester can go further following the rules described as above. The tester should notice that the current location is still in "Profile" tab. The tester can tab the back button on the top and go back to the "Profile" page.

The user's contact information is included as well. The tester can try "Email" button, which will open the default email app. If there is no public email associated with that user, the email address passed in will be empty.
