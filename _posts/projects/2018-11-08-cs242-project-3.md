## General UI

When launching the application, the tester should first see a page with a tab bar at the bottom. There are four sections: "Repositories", "Following", "Followers", "Profile".

### Repositories Page

The "Repositories" page contains information of a user's repositories, including the ones he or she owns or has contributed to. For each entry, the owner's username, the repository's name and the description are included.

#### Star/Unstar

The user can see whether he or she has starred the repository based on the color of the star. The user can star/unstar a repository via this app, and the change is reflected in the UI via the star icon and the count immediately.

#### External Link

Entries have a clickable external link. The tester can open the webpage within the app. The tester can choose to open the webpage in Safari as well.

### Following Page

The "Following" page contains information of the users that the user follows. For each entry, the user's username and the avatar are included.

| Following 1                                                              | Following 2                                                              |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| ![Following](/assets/posts/2018-11-08-cs242-project-3/2_Following_1.png) | ![Following](/assets/posts/2018-11-08-cs242-project-3/2_Following_2.png) |

Entries are clickable. The tester can open the "Profile" page for a particular user. The tester should notice that the current location is still in the "Following" tab. The tester can tap the back button on the top and go back to the "Following" page.

### Followers Page

The "Followers" page contains information of the user's followers. Similarly, for each entry, the user's username and the avatar are included.

Entries are clickable. The tester can open the "Profile" page for a particular user. The tester should notice that the current location is still in the "Followers" tab. The tester can tap the back button on the top and go back to the "Followers" page.

### Profile Page

The "Profile" page contains the user's information, including the avatar, name, username, created date, number of repositories, number of following, number of followers, and the bio.

Three counts are clickable. The tester can open the "Repositories"/"Following"/"Followers" pages by tapping the buttons accordingly. The tester can go further following the rules described as above. The tester should notice that the current location is still in the "Profile" tab. The tester can tap the back button on the top and go back to the "Profile" page.

#### Contact

The user's contact information is included as well. The tester can try the "Email" button, which will open the default email app. If there is no public email associated with that user, the email address passed in will be empty. The tester can also try the "Website" button, which will open a webpage in the app.
