This is a five-week project building a photo sharing app using [React](https://reactjs.org/){:target="\_blank"} and [MongoDB](https://www.mongodb.com/){:target="\_blank"}. The frontend uses [Material-UI](https://material-ui.com/){:target="\_blank"} with customization. The focuses are more on implementing functionalities than designing and building nice-looking interfaces so please don't criticize too much on UI/UX :(

Most of the features are explained below; also a [demo](https://www.youtube.com/watch?v=7p5JuSYVWj4){:target="\_blank"} is linked for reference.

## Main Components

Users need to register and login to use our app. Validations are implemented both in the frontend and the backend.

![User Registration](/assets/posts/2021-03-19-photo-app/1-registration.png)

<p class="img-caption">Figure 1: User Registration</p>

![User Login](/assets/posts/2021-03-19-photo-app/1-login.png)

<p class="img-caption">Figure 2: User Login</p>

A toolbar on the top supports some users' actions. A list of existing users on the left, with the current user highlighted, provides navigation to the user details of all the users in our system. The main content on the right can either be users' profiles, or all photos belonging to that specified user.

![User Detail](/assets/posts/2021-03-19-photo-app/2-user-detail.png)

<p class="img-caption">Figure 3: User Detail</p>

![User Photos](/assets/posts/2021-03-19-photo-app/3-user-photos.png)

<p class="img-caption">Figure 4: User Photos</p>

**Advanced Features**: With advanced mode enabled by checking the box on the toolbar, the view changes to a photo viewer that only shows one photo at a time with a mechanism to step forward or backward.

![User Photos (Advanced Mode)](/assets/posts/2021-03-19-photo-app/3-user-photos-advanced.png)

<p class="img-caption">Figure 5: User Photos (Advanced Mode)</p>

## Upload Photos and Add Comments

Users can upload photos from their local machine by pressing the "Add Photo" button. Users can also comment on their or others' photos.

![Upload Photos](/assets/posts/2021-03-19-photo-app/3-user-photos-new.png)

<p class="img-caption">Figure 6: Upload Photos</p>

![Upload Photos](/assets/posts/2021-03-19-photo-app/3-user-photos-2.png)

<p class="img-caption">Figure 7: Upload Photos</p>

![Comments](/assets/posts/2021-03-19-photo-app/4-comments.png)

<p class="img-caption">Figure 8: Comments</p>

**Advanced Features**: The sidebar displays counts of photos (green) and comments (red) by each user; clicking on the comment count will display a collection of all comments by each user, grouped by photos. Clicking on any cell, users will be redirected to the photo view containing that comment.

![All Comments by User](/assets/posts/2021-03-19-photo-app/4-comments-all.png)

<p class="img-caption">Figure 9: All Comments by User</p>

## Additional Features

Users can save a photo to favorite. The toolbar provides an entry to view all photos saved by the current user. By clicking on a photo, users can view the photo in a larger view via a popped-up window.

![Favorites](/assets/posts/2021-03-19-photo-app/5-favorites.png)

<p class="img-caption">Figure 10: Favorites</p>

![All Favorites by User](/assets/posts/2021-03-19-photo-app/5-favorites-all.png)

<p class="img-caption">Figure 11: All Favorites by User</p>

Users can like and unlike a photo. The photo list is sorted by the number of likes in descending order.

![Likes](/assets/posts/2021-03-19-photo-app/6-likes.png)

<p class="img-caption">Figure 12: Likes</p>

Users can mention any existing users in comments by typing @. On users' profiles, there is a section displaying all the photos that mention the specified user.
